# Final project overview: Create a prototype to simulate an automatic umbrella for people who are unable to open an umbrella themselves. The system warns someone when it is raining and keeps them dry.

Worked with Samuel Underwood and Brandon Nguyen for this project.

September 23rd - We designed the prototype for our project and connected all wires to the different components on the breadboard. We crafted a code using our own knowledge and the use of ChatGPT to make it so when the humidity sensor reaches an ADC reading of 5 or greater, the umbrella arm goes up and the red LED starts blinking. When the contact switch is pressed, the umbrella goes down and the LED turns off.

September 28th - We refined the code to make the LED light blink faster when it is raining hard and slowing when there is light rain. We also created a cardboard box to hold our system up and simulate the umbrella being connected to the side of the wheel chair. We also began working on creating the slideshow presentation.

September 30th - We completed the design of the prototype and continued to work on the slideshow.

October 5th - Demonstrated our prototype functioning, finished making presentation, and practiced presenting.

October 7th - Presented our project to the class.
